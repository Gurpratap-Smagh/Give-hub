# GiveHub   

**Live**: [https://give-hub-nngk.vercel.app/](https://give-hub-nngk.vercel.app/)  

**Monorepo**: Houses Next.js frontend, backend services, Solidity contracts (security + versioned deploys).  

**Deployment**: Containerized on Google Cloud, IAM-locked.  
**Database**: MongoDB  
**Blockchain**: Cross-chain (ZetaChain / Ethereum / etc.)  

---

## Features

- Campaign creation + admin dashboard  
- Cross-chain donation support  
- Auto swap & forward—no custody, immediate payout  
- UI / UX upgrades (if any)  
- Possibly versioned contracts + safety checks  

---

## Tech Stack

- Frontend: Next.js + TypeScript  
- Backend: Node/Express  
- Contracts: Solidity  
- DB: MongoDB  
- Infra: Containers on GCP with IAM
